# Miner Detector

Детектор майнеров для Windows на Python.

## Что делает

- Мониторит процессы в реальном времени.
- Проверяет их по эвристикам (CPU, путь, подпись, окна).
- Ставит score от 0 до 100 — насколько процесс похож на майнер.
- Проверяет сетевые соединения на майнинг-пулы.
- Анализирует автозагрузку Windows.
- Показывает всё в GUI с вкладками.
- Позволяет убить подозрительный процесс.
